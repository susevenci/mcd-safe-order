# 麦麦安心点

用麦当劳 MCP 的真实营养数据，把整份菜单按用户的人群画像筛成三档：**可以点 / 注意着点 / 先别点**。

## 何时使用

- 用户要为老人、儿童、孕妇、慢性病人群点餐
- 用户问某种忌口/过敏能不能避开
- 用户有热量、钠、糖的具体限制

## 执行步骤

1. **确认画像**。从下面选，或让用户自定义：
   `child 儿童` / `elder 老人` / `pregnant 孕产` / `fatloss 减脂` / `hypertension 控钠` / `lowsugar 控糖` / `vegetarian 素食`
2. **跑筛查**：

   ```bash
   python -m src.cli screen --profile <画像> --top 8
   ```
3. **要组合**用 `combo`，要分享图纸用 `--html 路径`。
4. **讲解结论**：说清这个人**超在哪一项、超了多少**，并给同类替代。

## 表达要求

- 给出具体数值，不要说"这个比较健康"。
- 过敏相关必须补一句：判定基于餐品名称关键词推断，请以麦当劳官方配料说明为准。
- 用户是特殊人群时，结尾提醒：不构成医疗建议。

## 安全约束

- 只调用只读工具（`list-nutrition-foods`、`query-my-account`），**不下单、不消耗积分**。
- 营养字段缺失时说"数据缺失"，不得当成 0。
- 离线样例数据必须声明是示例，不得冒充实时数据。
